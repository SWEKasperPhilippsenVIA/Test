# AI-agenter i softwareudvikling – SEP1

Individuel Java-øvelse med søgning i en lille Pokémon-kortsamling fra Neo-serien. Arbejdet ligger i dette selvstændige repository og påvirker ikke gruppens semesterprojekt.

## Struktur

- `src/` – Java-klasser og en simpel testkørsel i `Main`.
- `docs/` – agentprompt, arbejdsgang og testnoter.

## Kør programmet

Kræver en installeret JDK (Java 17+):

```bash
javac -d out src/*.java
java -cp out Main
```

Dokumentationen skelner mellem verificerede værktøjshandlinger og den del, som kræver selvstændig udførelse i IntelliJ/Claude Agent.
